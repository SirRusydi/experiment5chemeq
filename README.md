# EquiLab SK015 Final V4

Finalized student practical companion for Experiment 5: Chemical Equilibrium.

Key additions:
- Part C has a complete step-by-step experimental procedure.
- Guided Kc calculation using the agreed dilution method:
  1. Vwater = Vfinal - Vinitial
  2. Vfinal = 5.00 mL + Vwater
  3. [HCl]eq = (6.00 × 5.00) / Vfinal
  4. [SbCl3]eq = (0.500 × 5.00) / Vfinal
  5. Kc = [HCl]^2 / [SbCl3]
- No ICE table is used.
- Calculation checks provide immediate feedback and hints.
- Save/completion buttons visibly change to a green checked state.
- Report structure remains: Title, Objectives, Introduction, Procedure, Results, Calculations, Discussions, Conclusion.
- DOCX generation and print support retained.
- Student data and progress are stored locally in the browser.
